# Alt Afrikaner | Investigations readability and editorial audit

Audit opened 21 October 2026. Scope: the **31 investigation cards** on `index.html`, linking to **29 local HTML investigations** and two off-site investigations at `citizenintel.github.io`. Counts and source signals are generated by `node scripts/audit-investigations.mjs --json`; run it after every editorial change.

## What has been implemented in this phase

- Scoped high-contrast overrides for published local investigations in `assets/investigation-contrast.css`. The Real411 `#whorunsit` data table and IEC explainer use explicit dark foreground on light panels. Colour pairs are checked against a WCAG AA 4.5:1 body-text target.
- Added a final contrast stylesheet link to the 28 regular-sized local dossier HTML files. The unusually large `MTNrooivalkIRAN.html` archive receives a scoped correction through its existing `assets/dossier-batch-16-18.css` so that the research file need not be rewritten merely to change colours.
- Added automated checks for the full 31-card index and 29 local page contrast coverage. **A static contrast test does not replace a browser/device visual audit.**

## Editorial review standard

The user's target is **at least 1,500 words**, with an improvement review for files below 1,550. The minimum is **not** permission to pad with filler or invent research. Existing source material, citations, script-driven charts and diagram text must be kept. The automated audit calculates **approximate readable narrative words**, excluding scripts, SVG, navigation, footers and data tables. Infographic-first dossiers can register short even when visually information-rich. The report is a triage tool, not an accuracy certification.

Each investigation needs: (1) plain-language introduction for unfamiliar international readers; (2) clear chain from documents to claims; (3) an account of how its mechanism works; (4) source provenance with **two independent sources** for contested facts whenever available; (5) explicit **UNVERIFIED** flags for missing support; (6) a meaningful conclusion distinguishing evidence from inference; and (7) working internal and external links.

## External-site exception

The two externally hosted investigation cards (CitizenIntel Kalahari and AAIT) are **outside this GitHub repository**, so GitHub changes here cannot repair their source HTML. Their URLs remain in the archive; assess them on their own repositories before declaring full-site visual coverage.

## Release criteria

- GitHub Actions dossier checks and contrast inventory pass.
- Existing research claims, scripts, SVGs, IDs and image data remain preserved for design-only changes.
- No unsourced length padding, fabricated citations, or unverified allegations introduced.
- Browser checks remain a separate step: desktop/mobile, dark/light plates, hover, focus, and reading contrast in tables and callout boxes.
